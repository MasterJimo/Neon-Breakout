PRIVACY POLICY

How the current version of Neon Breakout handles game information.

Last updated: 20 October 2026

Current version: the game has no account sign-up, online leaderboard, third-party analytics, advertising scripts or donation checkout. This notice will need updating if those features are added.

Who operates this game?

Neon Breakout is created by MrJim. For project questions, you can use the public GitHub issues page. Please do not post sensitive or private information there.

Gameplay information

Your score, remaining lives, sector progression, paddle movement and power-ups are handled in the browser while you play. The current game does not submit these details to an online leaderboard or create a player profile.

Local browser storage

To remember your best score, the game uses localStorage under the key neon-breakout-best. This stays in your browser for this site unless you clear its stored data. You can remove this record through your browser's site data controls.

Hosting and connection information

The game is served by GitHub Pages. GitHub may receive technical connection data, such as your IP address and browser request details, when delivering the site. See the GitHub Privacy Statement.

Ads, cookies and payments

Neon Breakout currently does not include ad-network or payment scripts. If ads, analytics, donations or other third-party services are introduced later, this page will be revised to explain those services and relevant user choices. Any required consent arrangements will be added before such services are enabled.

Contact and updates

This notice reflects the current published game code and will be updated when its data practices change. Project-related questions can be raised through the game's GitHub repository.
